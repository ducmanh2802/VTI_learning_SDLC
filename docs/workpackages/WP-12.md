## Goal

After every quote cycle, Analytics computes and caches the market overview in Redis within 5 s:

- indices;
- breadth per exchange;
- % of stocks above MA20/50/200;
- top movers;
- treemap data;
- a neutral, rule-based market card.

After the end-of-day bars, it stores indicator snapshots for every symbol.

The overview must **degrade explicitly** when the data source tier lacks a capability. It never fabricates data.

## Facts about the data on the free (Guest) tier (measured 2026-10-21)

- Quotes have `reference`, `ceiling`, `floor` and `price`, but **no intraday matched volume or value**.
- **Industries are unavailable.**
- Index levels come from today's daily bar.

Therefore, on the Guest tier:

| Feature | Behaviour |
|---|---|
| Treemap weight `VALUE` | unavailable |
| "Volume spike" movers | unavailable |
| Treemap grouping | by **exchange** (HOSE/HNX/UPCOM) instead of industry |

When `VNSTOCK_API_KEY` raises the tier and the capability appears, the same code uses industries and volume automatically.

## Design

### Pure functions (`quant`, `Decimal` only)

**`pct_change(price, reference)`**

- `(price − reference) / reference × 100`, quantized to 0.01.
- `None` if either input is missing or `reference = 0`.

**`breadth(quotes) -> {exchange: {advancers, decliners, unchanged, ceiling, floor, total}}`**

- Advancers: `pct > 0`; decliners: `pct < 0`; unchanged: `pct = 0`.
- Ceiling: `price == ceiling`; floor: `price == floor`.
- Quotes with `price is None` are excluded and counted under `missing`.

**`pct_above_ma(snapshots) -> {20: Decimal|None, 50: ..., 200: ...}`**

- Uses the last close and the SMA from the EOD indicator snapshots.
- The denominator counts only symbols where that SMA exists.

**`movers(quotes, n=10)`**

- `gainers`: top n by pct; `losers`: bottom n.
- Ties are broken by symbol code ascending.
- Only symbols with `price` present.
- `volume_spike`: symbols with `matched_volume ≥ 2 × vol_ma20`. If no quote has `matched_volume`, return `None`.

**`treemap(quotes, groups, weight, direction)`**

- `groups: Mapping[str, str]` maps symbol → group label.
- `weight` is `VALUE`, `COUNT` or `ADVANCERS`:
  - `VALUE` needs `matched_value`, otherwise `CapabilityUnavailable`;
  - `COUNT` = 1 per symbol;
  - `ADVANCERS` = 1 if pct > 0, else 0.
- `direction`: `ALL`, `UP` (pct > 0) or `DOWN` (pct < 0) filters the symbols.
- Node output: `{group, weight_sum, pct_avg, leader, children: [{symbol, weight, pct}]}`.
  - `pct_avg` is weighted by `matched_value` when available, otherwise a simple mean.
  - `leader` = the child with the largest weight; ties go to the higher |pct|, then the code.

**`market_card(indices, breadth, vn30_breadth) -> tuple[CardLine, ...]`**

- Rule version `mkt-card-1`. Lines come from a fixed template table, for example:
  - "VN-Index {tăng|giảm|đứng} {x} điểm ({p}%)"
  - "HOSE có {a} mã tăng, {d} mã giảm, {u} mã đứng giá"
  - "Nhóm VN30 có {a} mã tăng, {d} mã giảm"
- Each line carries the input keys it used, for citations.
- **Neutral-language test:** same forbidden list as WP-11.

### Jobs

**`overview_job`** is called by the WP-10 hook after each successful quote cycle.

- **Inputs:**
  - every `q:*` (use pipelined `HGETALL`), `idx:*`;
  - the latest indicator snapshots: cache them in memory, refreshed when the EOD job finishes;
  - groups:
    - `INDUSTRIES` capability present → industry names;
    - otherwise → exchange.
- **Output:** `ov:latest`, a JSON matching the internal contract's overview schema. It includes:
  - `asOf`, `provenance`;
  - `unavailable: [...]`, listing every section missing because of a capability, for example `["volume_spike", "treemap_value"]`.
- **Treemaps:** precompute `ov:treemap:{weight}:{dir}` for each available weight and each direction. TTL 10 min.
- **Budget:** ≤ 1 s compute for 1,800 symbols (benchmark test).

**`indicator_snapshot_job`** runs right after WP-10 `eod_bars` succeeds.

- For each active stock and index, load ≤ 260 daily bars, call `compute_series` and `describe` from WP-11, and upsert `market.indicator_snapshots` with:
  - `rules_version`;
  - `indicator_values`: the latest snapshot, as strings;
  - `descriptions`: list of `{rule_id, text, inputs}`.
- Budget: ≤ 60 s for 1,800 symbols.

## Tests

| Area | Cases |
|---|---|
| `pct_change` | Rounding; a zero or missing reference |
| `breadth` | Synthetic quotes for each exchange, including ceiling, floor and missing |
| `pct_above_ma` | Missing SMAs are excluded from the denominator |
| `movers` | Ordering and ties; `volume_spike` is `None` without volume |
| `treemap` | Each weight and direction; `VALUE` without values → `CapabilityUnavailable`; leader selection; exchange fallback grouping |
| `market_card` | Templates and neutral language |
| `overview_job` (Redis testcontainer, fake quotes) | `ov:latest` validates against the internal contract schema (load the schema from `contracts/openapi/internal.yaml`); `unavailable` lists the right sections; TTLs are set |
| `indicator_snapshot_job` (Postgres testcontainer with migrations, synthetic bars) | Rows upserted; `rules_version` stored; idempotent |
| Benchmarks (`@pytest.mark.slow`) | Overview ≤ 1 s; snapshots ≤ 60 s |
| Coverage | New quant modules ≥ 90%; jobs ≥ 80% |
