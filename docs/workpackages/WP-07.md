## Goal

Create a buildable, tested Analytics service. It has:

- the package layout and layer rules;
- service-token authentication, a correlation-id middleware, JSON logs and RFC 9457 errors;
- health endpoints and pydantic models generated from the internal contract;
- a separate scheduler process, a container image and CI.

It contains **no** market-data or AI features yet: those start in WP-08, WP-11, WP-14 and WP-15.

## In scope

- `services/analytics/**` (new project)
- `infra/docker-compose.yml`: add `analytics` and `analytics-scheduler` under profile `app`
- `infra/.env.example`: Analytics variables only
- `.github/workflows/analytics.yml` (new)
- `services/analytics/README.md`, `docs/workpackages/reports/WP-07.md`

## Out of scope

- Any endpoint other than health.
- Provider adapters, jobs, quant, AI.
- Any change to `contracts/`.

## Tooling

- `uv` is installed on the machine. If `uv --version` fails, run `py -m pip install --user uv` and call it via `py -m uv`.
- Python 3.12 comes from `uv python install 3.12`. Do not use the system Python 3.15 for the project.
- All commands run through `uv run ...` inside `services/analytics`.

## Steps

### 1. Project

- `services/analytics/pyproject.toml`:
  - `requires-python = ">=3.12,<3.13"`, `src/` layout, package `analytics`.
- Runtime dependencies (latest stable, locked in `uv.lock`):
  - `fastapi`, `uvicorn[standard]`, `pydantic>=2`, `pydantic-settings`
  - `sqlalchemy>=2` + `asyncpg`, `redis>=5`, `httpx`, `tenacity`
  - `apscheduler>=3.10,<4`, `orjson`
- Dev dependencies:
  - `pytest`, `pytest-asyncio`, `pytest-cov`, `hypothesis`
  - `ruff`, `mypy`, `import-linter`
  - `testcontainers[postgres,redis]`
  - `datamodel-code-generator`

### 2. Package layout (SDD 3.2)

Create `src/analytics/{api,ingestion,ai,research,quant,fundamentals,marketdata,providers,common}/__init__.py`, plus `ai/llm/__init__.py` and `ai/guardrails/__init__.py`.

Put the three import-linter contracts from SDD 3.4.2 in `pyproject.toml` under `[tool.importlinter]`, with `root_package = "analytics"`:

- layers;
- `quant` is pure;
- `guardrails` is pure.

### 3. `common` (shared kernel)

- **Settings** (`pydantic-settings`), from env:
  - `ANALYTICS_DB_URL` (for example `postgresql+asyncpg://analytics_svc:...@postgres:5432/vnstockai`)
  - `REDIS_URL` (for example `redis://:password@redis:6379/0`)
  - `SERVICE_TOKEN` (min length 32)
  - `LOG_LEVEL`
- **Logging:** JSON (one object per line) with `ts`, `level`, `service="analytics"`, `correlationId`, `msg`. Use `contextvars` for the correlation id.
- **Time:** `TRADING_TZ = ZoneInfo("Asia/Ho_Chi_Minh")`, `utcnow()`, `trading_date(dt)`. No direct `datetime.now()` anywhere else.
- **Money:** helpers that parse VND to `int` and prices to `Decimal` (2 decimals); refuse floats.

### 4. API (`analytics.api`)

- `create_app()` factory. All routes are under `/internal/v1`.
- **Middleware:** correlation id. Read `X-Correlation-Id` (UUID) or generate one; echo it in the response.
- **Dependency `require_service_token`:**
  - Compare the `X-Service-Token` header with `hmac.compare_digest`.
  - On mismatch → 401 `application/problem+json` with `code=UNAUTHENTICATED`.
  - Applied to every route except health.
- **Exception handlers:** every error (`HTTPException`, `RequestValidationError`, unhandled) becomes RFC 9457 `{type, title, status, detail, code, correlationId}`. Unhandled → 500 `INTERNAL_ERROR`, with no stack trace in the body.
- **Health:**
  - `GET /internal/v1/health/live` → 200 `{"status":"UP"}`.
  - `GET /internal/v1/health/ready` → 200 only if `SELECT 1` on Postgres and `PING` on Redis both succeed within 2 s; otherwise 503 with the failing component.
- **Generated models:** generate pydantic v2 models from `../../contracts/openapi/internal.yaml` into `src/analytics/api/models_generated.py` with `datamodel-codegen`. Commit the generated file. Add the exact command to the README and as a script `scripts/gen_models.ps1` / `.sh`.
- **Probe route for tests:** add one internal test-only route `GET /internal/v1/_auth-probe`, protected by the token, used to test auth. Register it **only** when `settings.env == "test"`.

### 5. Scheduler process

- `python -m analytics.ingestion.scheduler` starts an APScheduler `AsyncIOScheduler` with no business jobs. It has one heartbeat job every 60 s that logs `{"msg":"scheduler heartbeat"}`.
- It exits cleanly on SIGTERM and SIGINT.

### 6. Container and compose

- `services/analytics/Dockerfile`:
  - Base `python:3.12-slim`; copy `uv` from `ghcr.io/astral-sh/uv` (pin a version tag).
  - `uv sync --frozen --no-dev`; non-root user.
  - The API runs `uvicorn analytics.api.main:app --host 0.0.0.0 --port 8090 --workers 2`.
- Compose services (profile `app`):
  - `analytics`: port `127.0.0.1:8090:8090` in dev only; `mem_limit: 2500m`; healthcheck on `/internal/v1/health/live`.
  - `analytics-scheduler`: same image, command `python -m analytics.ingestion.scheduler`.
  - Both use env `ANALYTICS_DB_URL` (user `analytics_svc`, password `${ANALYTICS_DB_PASSWORD}`), `REDIS_URL`, `SERVICE_TOKEN` from `.env`, and join network `internal`.
- `.env.example`: `SERVICE_TOKEN=change-me-service-token-at-least-32-chars`.

### 7. Tests (`uv run pytest`)

- **Live:** 200.
- **Ready, success:** 200 with real Postgres and Redis (testcontainers, after applying `../../db/migrations/*.sql` in order with `psql` or asyncpg).
- **Ready, failure:** 503 when Redis is unreachable (point the settings at a closed port).
- **Auth:** the probe route without token → 401 problem+json `UNAUTHENTICATED`; with a wrong token → 401; with the right token → 200.
- **Correlation id:** echo / replace / generate.
- **Error format:** validation error → 400 `VALIDATION_ERROR`; forced exception → 500 `INTERNAL_ERROR` without a traceback in the body.
- **Logging:** one request produces a JSON line containing `correlationId`.
- **Money and time helpers:** property tests with `hypothesis`.
- **Coverage:** ≥ 80% for `analytics.common` and `analytics.api`.

### 8. CI: `.github/workflows/analytics.yml`

- Triggers: like `core.yml`, with path filters `services/analytics/**`, `contracts/**`, `db/migrations/**`.
- Steps:
  1. `astral-sh/setup-uv` (pinned major) → `uv sync --frozen`.
  2. `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy --strict src`, `uv run lint-imports`.
  3. `uv run pytest --cov`.
  4. Regenerate the models and run `git diff --exit-code`.
