## Goal

Add `analytics.ai.llm`, a provider-agnostic LLM gateway:

- It calls free-tier providers in a configured order.
- It enforces per-provider daily caps and per-minute limits, and opens a circuit breaker on repeated failures.
- It returns `None` when nothing is available, so the caller (WP-16) can fall back to the facts table (FR-067).

It never logs prompt or response content.

## Design

### Types (`ai/llm/base.py`)

- `Message(role: Literal["system", "user", "assistant"], content: str)`
- `LlmRequest(messages: tuple[Message, ...], temperature: float = 0.2, max_tokens: int = 600, timeout_s: float = 15.0)`. A float is fine here: these are not money.
- `LlmResponse(text: str, provider: str, model: str, tokens_in: int | None, tokens_out: int | None, latency_ms: int)`
- Errors: `QuotaExceeded(provider, retry_after_s: int | None)`, `ProviderError(provider, status: int | None)`, `ProviderTimeout(provider)`.
- Protocol `LlmProvider`: `name: str`, `async complete(req) -> LlmResponse`.

### Adapter: one `OpenAICompatibleProvider`

The three free providers expose an OpenAI-compatible chat-completions API. Use `httpx.AsyncClient` (no vendor SDK) with:

| Provider | Base URL |
|---|---|
| `groq` | `https://api.groq.com/openai/v1` |
| `gemini` | `https://generativelanguage.googleapis.com/v1beta/openai` |
| `openrouter` | `https://openrouter.ai/api/v1`; send `HTTP-Referer` and `X-Title: VN Stock AI Pro`; only models ending in `:free` are allowed, enforced at config load |

Every adapter does `POST {base}/chat/completions` with `Authorization: Bearer <key>`, and maps:

| Response | Maps to |
|---|---|
| 200 | `choices[0].message.content` and `usage` |
| 429 | `QuotaExceeded` (read the `Retry-After` header) |
| 401, 403 | `ProviderError` (log once at WARNING: "credentials rejected", never the key) |
| 5xx | `ProviderError` |
| timeout | `ProviderTimeout` |
| empty content | `ProviderError` |

### Configuration (env, via settings)

- `LLM_PROVIDERS=groq,gemini,openrouter` sets the order.
- For each provider `P` in `{GROQ, GEMINI, OPENROUTER}`: `P_API_KEY`, `P_MODEL`, `P_DAILY_CAP`, `P_RPM`.
- Defaults:
  - Groq: `gpt-oss-120b`, cap 900, RPM 25.
  - Gemini: model empty, cap 200, RPM 10.
  - OpenRouter: model empty, cap 45, RPM 15.
- A provider with an empty key or model is **disabled**. This is logged once at startup; it is not an error.
- The founder must take current quota numbers from each provider's official page. The README says so and links the pages.

### Gateway (`ai/llm/gateway.py`, ALG-08)

`async complete(req) -> LlmResponse | None`:

1. For each enabled provider in order:
   - Skip it if its breaker is open (open for 5 min after 3 consecutive failures; half-open after that, one trial call).
   - Skip it if its daily budget is used up: Redis `INCR ai:budget:{provider}:{yyyymmdd}` (VN date) with a 48 h TTL; above the cap → `DECR` and skip.
   - Skip it if the minute bucket is empty (in-process token bucket, RPM).
   - Call it. On success, record success and return.
   - On `QuotaExceeded`, `ProviderError` or `ProviderTimeout`, record a failure and continue.
2. Return `None` when every provider is skipped or failed.

Other rules:

- **Logging:** one JSON line per attempt with `provider`, `model`, `outcome`, `latency_ms`, `tokens_in`, `tokens_out`, and **no** prompt or response text.
- **Clock and Redis:** both are injectable (use `fakeredis` in unit tests or a Redis testcontainer).

## Tests

| Area | Cases |
|---|---|
| Adapter (respx) | Success parsing, including usage; 429 with `Retry-After` → `QuotaExceeded`; 401 → `ProviderError` and the key does not appear in captured logs; 503 → `ProviderError`; timeout → `ProviderTimeout`; empty content → `ProviderError`; OpenRouter model without `:free` → config error at load |
| Gateway: order and failover | Groq 429 → Gemini 200 → returns Gemini; all fail → `None` |
| Gateway: breaker | 3 consecutive failures → skipped for 5 min (fake clock) → half-open trial |
| Gateway: daily cap | Reaching the cap skips the provider; the counter key has a TTL; the date rolls over at 00:00 Asia/Ho_Chi_Minh |
| Gateway: RPM | Over the RPM, the provider is skipped within the same minute |
| Gateway: disabled | A provider with an empty key is never called |
| Privacy | Prompt text never appears in any log record (`caplog`) |
| Live (`@pytest.mark.live`, skipped by default) | One short completion per configured provider; skipped automatically when no key is set |
| Coverage | `analytics.ai.llm` ≥ 85% |
