## Goal

Add `analytics.quant.indicators` and `analytics.quant.rules`. They are pure, deterministic functions that:

- compute SMA(20, 50, 200), EMA(12, 26), RSI(14), MACD(12, 26, 9), Bollinger(20, 2), ATR(14) and volume MA(20) from daily bars;
- produce **neutral** Vietnamese descriptions from a versioned rule table.

The AI pipeline (WP-16) and the indicators endpoint use these outputs.

## Definitions (SDD ALG-04; must match the golden file)

### Types

- `Bar(trade_date: date, open: Decimal, high: Decimal, low: Decimal, close: Decimal, volume: int)`, frozen.
- Every output value is `Decimal | None`, quantized to `0.01` with `ROUND_HALF_UP`.
- Never use `float` anywhere: inputs, intermediate values or outputs. Use `Decimal` arithmetic with a local context (`prec=28`). `Decimal.sqrt()` is allowed.

### Formulas

| Indicator | Definition |
|---|---|
| SMA(n) | Mean of the last n closes. `None` until n bars exist |
| EMA(n) | Seed = SMA(n) at index n−1; then `k = 2/(n+1)`, `EMA_t = k·C_t + (1−k)·EMA_{t−1}` |
| RSI(14), Wilder | `gain_t = max(C_t − C_{t−1}, 0)`, `loss_t = max(C_{t−1} − C_t, 0)` for t ≥ 1. First value at index 14: `avgGain` = mean of `gain_1..gain_14`, `avgLoss` likewise. Then `avg = (avg·13 + x_t)/14`. RSI = 100 if `avgLoss = 0`, else `100 − 100/(1 + avgGain/avgLoss)` |
| MACD(12, 26, 9) | `line = EMA12 − EMA26` (from index 25). `signal` = EMA9 of `line`, seeded with the SMA of the first 9 line values, so the first value is at index 33. `hist = line − signal` |
| Bollinger(20, 2) | `mid = SMA20`; upper/lower = `mid ± 2·σ`, with σ the **population** std (divide by n) of the same 20 closes |
| ATR(14), Wilder | `TR_0 = H_0 − L_0`; for t ≥ 1, `TR_t = max(H−L, |H−C_{t−1}|, |L−C_{t−1}|)`. First ATR at index 14 = mean(`TR_1..TR_14`), then `ATR_t = (ATR_{t−1}·13 + TR_t)/14` |
| Volume MA(20) | SMA20 of volume, as `Decimal`, quantized to 0.01 |

### Complexity

- Every series must be **O(n)**: use running sums for SMA and Bollinger, keeping a running sum of squares; do not re-sum each window.
- Budget: 250 bars × 1,700 symbols must finish in **≤ 60 s** on the dev machine. Add a benchmark test marked `@pytest.mark.slow`.

## Rule table `ind-rules-1`

Evaluate each rule on the **last** bar. If a required input is `None`, the rule is skipped and emits nothing. Texts are exact.

| rule_id | Condition | Text |
|---|---|---|
| `rsi_zone` | rsi14 > 70 / rsi14 < 30 / otherwise | "RSI(14) ở vùng quá mua theo quy ước" / "RSI(14) ở vùng quá bán theo quy ước" / "RSI(14) ở vùng trung tính" |
| `price_vs_sma20` | close > / < / = sma20 | "Giá đóng cửa nằm trên MA20" / "Giá đóng cửa nằm dưới MA20" / "Giá đóng cửa bằng MA20" |
| `price_vs_sma50` | same as above with sma50 | "... MA50" |
| `price_vs_sma200` | same as above with sma200 | "... MA200" |
| `sma50_vs_sma200` | sma50 > / < sma200 | "MA50 nằm trên MA200" / "MA50 nằm dưới MA200" |
| `macd_cross` | line crossed above signal within the last 3 bars (`line_{t−1} ≤ signal_{t−1}` and `line_t > signal_t` for some t among the last 3) / crossed below likewise / else line > signal / else | "MACD vừa cắt lên đường tín hiệu" / "MACD vừa cắt xuống đường tín hiệu" / "MACD đang nằm trên đường tín hiệu" / "MACD đang nằm dưới đường tín hiệu" |
| `bollinger_pos` | close > bb_upper / close < bb_lower / else | "Giá đóng cửa vượt dải trên Bollinger" / "Giá đóng cửa nằm dưới dải dưới Bollinger" / "Giá đóng cửa nằm trong dải Bollinger" |
| `volume_spike` | volume ≥ 2 × vol_ma20 | "Khối lượng phiên gấp ít nhất 2 lần trung bình 20 phiên" (no text otherwise) |
| `atr_pct` | always, if atr14 and close exist | "ATR(14) bằng {p}% giá đóng cửa", with `p = round(atr14/close·100, 2)` formatted vi-VN (comma decimal) |

**Neutral language:** a unit test asserts that **no** rule text contains any of: `nên`, `khuyến nghị`, `mua vào`, `bán ra`, `điểm mua`, `điểm bán`, `cơ hội`, `chắc chắn`, `giá mục tiêu`, `sẽ tăng`, `sẽ giảm`. Matching is case-insensitive, on the text with and without diacritics.

## Tests

| Test | What it checks |
|---|---|
| Golden | Rebuild the dataset from the formulas in the fixture. Every series equals the golden values within `0.01` at the listed indices, and is `None` exactly where golden is null. `first_valid_index` matches |
| Property (`hypothesis`) | Constant closes: SMA = EMA = close, Bollinger width = 0, RSI = 100 (no losses; document this convention). Strictly increasing closes: RSI = 100. RSI ∈ [0, 100]. `bb_upper ≥ bb_mid ≥ bb_lower`. ATR ≥ 0. Every output is `Decimal` or `None`, never `float` |
| Rules | One test per rule and branch, with hand-built bar sequences. Skipped when inputs are `None`. `RULES_VERSION` constant |
| Neutral language | As described above |
| Input validation | Unsorted or duplicate dates → `ValueError` |
| Coverage | `analytics.quant` ≥ 90% |
