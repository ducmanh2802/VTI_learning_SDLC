## Goal

Create a buildable, tested Core service. It has the module skeleton, the shared kernel (errors, correlation id, clock, money types), a deny-by-default security chain, health endpoints, a container image, and CI.

It contains **no business features** yet: identity starts in WP-04.

## In scope

- `services/core/**` (new project)
- No contract change: `GET /health` is already defined by WP-02. Read contracts from `contracts/openapi/dist/public.yaml`, the bundled file.
- `infra/docker-compose.yml`: add service `core` under profile `app`
- `infra/.env.example`: add only the variables that Core needs
- `.github/workflows/core.yml` (new; do not edit other workflows)
- `services/core/README.md`, `docs/workpackages/reports/WP-03.md`

## Out of scope

- Any endpoint other than `/health`.
- JWT issuance (WP-04).
- Entities for business tables.

## Steps

### 1. Generate the project (do not hand-write Gradle from memory)

1. Read `https://start.spring.io/metadata/client` and pick the **default GA** `bootVersion`. It is 4.1.x at the time of writing.
2. Download the starter with these parameters:
   - `type=gradle-project-kotlin`, `language=java`, `javaVersion=21`
   - `groupId=vn.stockai`, `artifactId=core`, `name=core`, `packageName=vn.stockai.core`
   - `dependencies=web,security,oauth2-resource-server,data-jpa,validation,actuator,modulith,postgresql,data-redis,testcontainers`

   If an id is rejected, read the error, use the current id and note it in the report.
3. Unzip into `services/core`. Keep the Gradle wrapper (`gradlew`, `gradlew.bat`, `gradle/wrapper/*`).
4. In `settings.gradle.kts` add the plugin `org.gradle.toolchains.foojay-resolver-convention`, so Gradle downloads JDK 21 automatically. The machine only has JDK 17, and Gradle may run on it.

- Every module except `shared` declares `@ApplicationModule(allowedDependencies = {...})` exactly as in the table above.
- Each module has an `api` sub-package annotated `@NamedInterface("api")`. It may be empty, apart from `package-info.java`.

### 3. Shared kernel (`vn.stockai.core.shared`)

- **`ErrorCode` enum:** exactly the `Problem.code` enum from `contracts/openapi/dist/public.yaml`.
- **`ApiException(ErrorCode code, HttpStatus status, String detail)`:** a runtime exception.
- **`@RestControllerAdvice ProblemHandler`** (extends `ResponseEntityExceptionHandler`):
  - Every error becomes `application/problem+json` with `type`, `title`, `status`, `detail`, `code`, `correlationId`.
  - Validation errors use `code=VALIDATION_ERROR` and an `errors[{field, message}]` list.
  - Unknown exceptions use `INTERNAL_ERROR`, and never expose stack traces or exception messages.
- **`CorrelationIdFilter`** (highest precedence):
  - Read `X-Correlation-Id` if it is a valid UUID; otherwise generate one.
  - Put it in MDC as `correlationId`, echo it in the response header, and clear MDC afterwards.
- **Structured JSON logs:** `logging.structured.format.console=logstash` (Spring Boot structured logging). Every log line must contain `correlationId` when inside a request.
- **Time:** a `Clock` bean (`Clock.systemUTC()`), and `TradingTime.ZONE = ZoneId.of("Asia/Ho_Chi_Minh")` with a helper `LocalDate tradingDate(Instant)`.
- **Money types (SC-012):**
  - `record Vnd(long amount)`: no negative zero; with `plus`, `minus`, `times(long)`.
  - `record Price(BigDecimal value)`: scale exactly 2, must be > 0.
  - Unit tests for both.
- **API prefix:** a `WebMvcConfigurer` adds the prefix `/api/v1` to every `@RestController` in `vn.stockai.core`.

### 4. Security baseline

- **Filter chain:** stateless, `csrf` disabled (refresh-cookie CSRF is handled in WP-04 with `SameSite=Strict`), CORS allow-list from the property `app.cors.allowed-origins` (empty by default).
- **Public paths:** `GET /api/v1/health`, `/api/v1/content/**`, `/api/v1/auth/**`, `/actuator/health/**`. Everything else requires authentication.
- **Resource server:** configure an OAuth2 resource server with a JWT decoder built from an **RSA public key** read from the property `app.jwt.public-key-pem`.
  - In dev and test, generate an ephemeral keypair at startup when the property is empty.
  - WP-04 will add the private key and issuance.
- **Error bodies:**
  - 401: `Problem` with code `UNAUTHENTICATED`.
  - 403: `Problem` with code `FORBIDDEN`.
  - Both use the same JSON writer as `ProblemHandler`.
- **Headers:** `Strict-Transport-Security` (only on HTTPS requests), `X-Content-Type-Options`, `Referrer-Policy: no-referrer`.

### 5. Health (FR-222)

- `GET /api/v1/health` returns `{status, components: {db, redis}}`. Status 200 if both are up, otherwise 503.
- Use Actuator `HealthEndpoint` contributors; do not re-implement the checks.
- Expose only `health` on actuator, with liveness/readiness groups.

### 6. Configuration (`application.yml` + `application-dev.yml`)

- Datasource from env:
  - `CORE_DB_URL` (default `jdbc:postgresql://localhost:5432/vnstockai`)
  - `CORE_DB_USER` (`core_svc`)
  - `CORE_DB_PASSWORD`
- Hikari pool size 20.
- `spring.jpa.open-in-view=false`, `spring.jpa.hibernate.ddl-auto=validate`.
- `spring.flyway.enabled=false`: the migrator owns migrations.
- Redis from env: `REDIS_HOST`, `REDIS_PORT`, `REDIS_PASSWORD`.
- `spring.threads.virtual.enabled=true`.
- `server.shutdown=graceful`.

### 7. Tests (JUnit 5 + AssertJ; `./gradlew build` must run them)

- **`ModularityTests`:** `ApplicationModules.of(CoreApplication.class).verify()`.
- **`ProblemHandlerTest`** (MockMvc):
  - Validation → 400 `VALIDATION_ERROR` with `errors`.
  - Unknown exception → 500 `INTERNAL_ERROR` without a stack trace.
  - Protected path without token → 401 `UNAUTHENTICATED` problem+json.
- **`CorrelationIdFilterTest`:** echoes a valid header; replaces an invalid one; generates one when absent.
- **`MoneyTypesTest`.**
- **`CoreApplicationIT`** (Testcontainers `postgres:16-alpine` and `redis:7-alpine`):
  - Before the context starts, apply `../../db/migrations` with Flyway (test-only dependency `org.flywaydb:flyway-core` + `flyway-database-postgresql`).
  - Context loads with `ddl-auto=validate`.
  - `/api/v1/health` returns 200 `UP`.
- **`ContractPathsTest`:**
  - Parse `../../contracts/openapi/dist/public.yaml` (bundled, so no `$ref` across files) with SnakeYAML.
  - Assert that every `@RequestMapping` exposed by the app (excluding actuator and error) appears in the contract with the same method and path.
  - This enforces "no undocumented endpoint" (NFR-M02).
- **JaCoCo:** fail the build if line coverage of `vn.stockai.core.shared` is < 80%.

### 8. Container image and compose

- `services/core/Dockerfile`:
  - Multi-stage: `eclipse-temurin:21-jdk` build → `eclipse-temurin:21-jre` runtime.
  - Non-root user. `JAVA_TOOL_OPTIONS=-Xmx1280m -XX:+UseZGC` (SDD 3.10.2).
  - `HEALTHCHECK` using `/api/v1/health`.
- Compose service `core`:
  - `profiles: ["app"]`, `build: ../services/core`, `depends_on` postgres and redis healthy.
  - Env from `.env`: `CORE_DB_URL=jdbc:postgresql://postgres:5432/${POSTGRES_DB}`, `CORE_DB_USER=core_svc`, `CORE_DB_PASSWORD`, `REDIS_HOST=redis`, `REDIS_PASSWORD`.
  - `ports: ["127.0.0.1:8080:8080"]`, `mem_limit: 2g`, network `internal`.

### 9. CI: `.github/workflows/core.yml`

- Triggers: `pull_request`, and `push` on `main`, `integration/**`, `wp-*`, with path filters `services/core/**`, `contracts/**`, `db/migrations/**`.
- Steps:
  1. `actions/setup-java@v4` (Temurin 21).
  2. `./gradlew build` in `services/core`.
  3. Upload the test report on failure.
- `permissions: contents: read`.
