## Goal

Create the empty but working repository structure so the following WPs can start in parallel:

- A dev `docker compose` that starts PostgreSQL 16 and Redis 7 healthy on localhost.
- A CI workflow that validates and smoke-tests that compose file and scans for secrets.
- Repo hygiene files: `.gitignore`, `.gitattributes`, `.editorconfig`, README.

## In scope (files you may create or edit)

- `README.md` (replace the current one-line README)
- `.gitignore`, `.gitattributes`, `.editorconfig`
- `infra/docker-compose.yml`, `infra/.env.example`, `infra/README.md`
- `apps/web/README.md`, `apps/mobile/README.md`, `services/core/README.md`, `services/analytics/README.md`
- `contracts/openapi/README.md`, `contracts/events/README.md`, `db/migrations/README.md`
- `docs/workpackages/reports/README.md`, `docs/workpackages/reports/WP-00.md` (your report)

## Out of scope (do not do)

- Any application code or build files: no Gradle, no `pyproject.toml`, no `package.json`. These come in WP-03, WP-07, WP-20a and WP-21.
- Migrations or a migrator service (WP-01).
- OpenAPI files (WP-02).
- Caddy, production compose, deployment, backups (WP-22).
- Editing `AGENTS.md`, `docs/requirements/**`, `docs/design/**`, the prompt files, or the `.xlsx` checklists.

## Steps

### 1. Hygiene files

**`.gitattributes`:**

- Set `* text=auto eol=lf`.
- Explicit binaries: `*.xlsx *.png *.jpg *.ico *.jar *.drawio.png binary`.
- `*.bat`, `*.cmd`, `*.ps1` → `eol=crlf`.
- `gradlew` → `eol=lf`.

Then run `git add --renormalize .`. Commit any line-ending changes in a **separate** commit: `chore: normalize line endings [WP-00]`.

**`.gitignore`** must cover:

- OS and IDE: `.DS_Store`, `Thumbs.db`, `.idea/`, `.vscode/*` (keep `!.vscode/extensions.json`), `*.iml`.
- Env files: `.env`, `.env.*`, keeping `!.env.example` and `!*.env.example`.
- Java/Gradle: `.gradle/`, `build/`, `out/`, `*.class`.
- Python: `__pycache__/`, `*.pyc`, `.venv/`, `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`, `.coverage`, `htmlcov/`.
- Node/Expo: `node_modules/`, `dist/`, `.expo/`, `*.tsbuildinfo`, `coverage/`.
- Local data and keys: `*.dump`, `*.age`, `backups/`, `*.pem`, `*.key`.

**`.editorconfig`:**

- `root = true`; UTF-8; LF; final newline; trim trailing whitespace (except `*.md`).
- Indent 4 spaces for `*.java`, `*.kt`, `*.kts`, `*.py`, `*.sql`.
- Indent 2 spaces for `*.ts`, `*.tsx`, `*.js`, `*.json`, `*.yml`, `*.yaml`, `*.md`.

### 4. `infra/docker-compose.yml` (dev)

- No top-level `version:` key. Top-level `name: ${COMPOSE_PROJECT_NAME:-vnstockai}`.
- Every required variable uses `${VAR:?message}`, so a missing value fails fast.

**Service `postgres`:**

- `image: postgres:16-alpine`
- Environment `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` from env.
- `command` sets (SDD 3.10.2): `shared_buffers=768MB`, `effective_cache_size=2GB`, `work_mem=16MB`, `max_connections=60`, `timezone=UTC`, `log_timezone=UTC`.
- `ports: ["127.0.0.1:${POSTGRES_PORT:-5432}:5432"]`. Must be bound to localhost only.
- Named volume `pgdata:/var/lib/postgresql/data`.
- `healthcheck`: `pg_isready -U "$${POSTGRES_USER}" -d "$${POSTGRES_DB}"`, interval 5s, timeout 3s, retries 20.
- `mem_limit: 3g`, `restart: unless-stopped`.

**Service `redis`:**

- `image: redis:7-alpine`
- `command`: `redis-server --appendonly yes --appendfsync everysec --maxmemory 384mb --maxmemory-policy volatile-lru --requirepass "$${REDIS_PASSWORD}"`. Use the shell form (`sh -c`) so the env var expands inside the container.
- Environment `REDIS_PASSWORD` from env, plus `REDISCLI_AUTH` set to the same value, so the healthcheck does not put the password on the command line.
- `ports: ["127.0.0.1:${REDIS_PORT:-6379}:6379"]`.
- Named volume `redisdata:/data`.
- `healthcheck`: `redis-cli ping | grep PONG`, interval 5s, timeout 3s, retries 20.
- `mem_limit: 512m`, `restart: unless-stopped`.

**Network:** one network named `internal` that both services join. Do **not** set `internal: true` in dev, because it would block localhost ports. WP-22 adds the production override.

**Header comment:** "Dev only. Production overrides come in WP-22 (no host ports, internal network)."

### 7. `.github/workflows/ci.yml`

- Triggers: `pull_request`, and `push` to `main`. Use `permissions: contents: read`.
- `concurrency`: cancel in-progress runs for the same ref.
- Pin every action to a released major version, for example `actions/checkout@v4`. Never use `@main` or `@master`.

**Job `secret-scan`:**

- Run gitleaks from its official Docker image, pinned to a specific `v8.x.y` tag (not `latest`): `detect --source . --no-banner --redact --exit-code 1`.
- The job must fail if a secret is found.
- Free for personal repos, no license key needed (SC-005).

**Job `compose-smoke`:**

1. `cp infra/.env.example infra/.env`
2. `docker compose -f infra/docker-compose.yml --env-file infra/.env config --quiet`
3. `docker compose -f infra/docker-compose.yml --env-file infra/.env up -d --wait --wait-timeout 120`
4. Run the checks from "Acceptance" items 3–6.
5. Always run `docker compose ... down -v` at the end (`if: always()`).

The whole workflow must finish in ≤ 5 minutes (NFR-D03 budget is 15 minutes for the full CI later).

## Acceptance (run all of these; paste the results in the report)

Run from the repo root after `cp infra/.env.example infra/.env`. `DC` below means `docker compose -f infra/docker-compose.yml --env-file infra/.env`.

| # | Command | Expected |
|---|---|---|
| 1 | `DC config --quiet` | exit 0, no output |
| 2 | `DC up -d --wait --wait-timeout 120` | exit 0; `DC ps` shows `postgres` and `redis` as `healthy` |
| 3 | `DC exec -T postgres pg_isready -U vnstockai -d vnstockai` | contains `accepting connections` |
| 4 | `DC exec -T postgres psql -U vnstockai -d vnstockai -tAc "SHOW shared_buffers"` | `768MB` |
| 5 | `DC exec -T redis redis-cli ping` | `PONG` (REDISCLI_AUTH is set) |
| 6 | `DC exec -T redis sh -c 'REDISCLI_AUTH= redis-cli ping'` | output contains `NOAUTH` (password is enforced) |
| 7 | `DC exec -T redis redis-cli CONFIG GET maxmemory-policy` | `volatile-lru` |
| 8 | `DC port postgres 5432` and `DC port redis 6379` | both start with `127.0.0.1:` |
| 9 | `git check-ignore infra/.env` | prints `infra/.env` |
| 10 | `git ls-files \| grep -E '(^\|/)\.env$'` | no output |
| 11 | CI on the PR | `secret-scan` and `compose-smoke` both green |
| 12 | `git ls-files` | contains every file listed under "In scope"; no file outside it, except line-ending renormalization from step 1 |
| 13 | `DC down -v` | exit 0 |

On Windows PowerShell, use `Select-String` instead of `grep` for #10. The CI runs on Linux.
