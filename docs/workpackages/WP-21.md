## Goal

An Expo (React Native, TypeScript) Android app for the core mobile journeys:

- login, logout and refresh with the token in **secure storage**;
- terms gate;
- watchlists;
- symbol detail (price, chart, neutral descriptions, AI summary with citations);
- AI chat;
- alerts with **Expo push**;
- paper trading (account, two-step ticket, positions).

Build an **APK** with EAS Build on the free tier, or locally. **No App Store work in R1** (SC-013).

## Design

**Project setup:**

- Expo SDK (latest stable) with `expo-router`, `expo-secure-store`, `expo-notifications`.
- `@tanstack/react-query` and `openapi-fetch` with types generated from `contracts/openapi/dist/public.yaml`, using the same script pattern as the web app.

**Shared code:** move pure helpers into a workspace package `packages/shared`: format, errors map, ticks, preview sentences, forbidden-copy list. Both the web and mobile apps use it.

- `pnpm-workspace.yaml` at the repo root, with `apps/*` and `packages/*`.
- Do the minimal refactor of the web imports, and keep the web tests green.

**Auth:**

- Login with `client=MOBILE`.
- The refresh token is stored with `SecureStore`; the access token is kept in memory.
- Refresh on 401, with one shared refresh, as on the web.

**Network:**

- API base URL from `app.config.ts` `extra.apiBaseUrl`. Dev: the LAN IP of the dev machine, port 8080, documented.
- HTTPS is required in release builds.

**Screens (bottom tabs):** Tổng quan (compact) · Theo dõi · Trợ lý AI · Giả lập · Tài khoản. The symbol detail screen is pushed from lists.

**Charts:** use a free React Native chart library that supports candlesticks (for example `react-native-wagmi-charts`), or render a simple line chart of close prices if candlesticks are not feasible. Report the choice.

**Push (FR-097):**

- Ask for permission only when the user creates the first PUSH alert.
- `getExpoPushTokenAsync` → `POST /devices {platform: EXPO, token}`.
- Tapping a notification opens the symbol screen via its deep link.

**Accessibility:** touch targets ≥ 44 px (NFR-U04) and `accessibilityLabel` on price changes.

## Tests

- **Jest with the React Native preset:** the auth store refresh logic (one shared refresh); secure-store use (mocked); the push permission timing; the shared helpers through the package tests.
- No device E2E is required in this WP. Maestro flows are written as files under `apps/mobile/e2e/` and run in WP-24 if a device or emulator is available.
