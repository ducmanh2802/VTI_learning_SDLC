# WP-08: Market-data provider port + vnstock adapter (rate limit, single-flight, provenance)

| Field | Value |
|---|---|
| Size | M |
| Audit level | Standard (A1–A10) |
| Branch | `wp-08-provider-vnstock` |
| Depends on | WP-07 |
| References | SRS IR-001, IR-002, FR-028, FR-030, FR-033, SC-006, SC-010, SC-012; SDD 3.3.2 (`MarketDataProvider`), ALG-03, ADR-007; BRD RSK-014, SRC-016 |

## Goal

The Analytics service can read market data from **vnstock 5.x** through one provider port, `MarketDataProvider`. Every value is normalized:

- VND as `int`, prices as `Decimal` with 2 decimals, UTC timestamps;
- provenance attached.

Calls are rate-limited and coalesced. **Capabilities that the current vnstock tier does not grant become explicit `CapabilityUnavailable` errors**, which drive fail-closed behaviour later. Results are never silently empty.

This WP does **not** write to the database or Redis. That is WP-10.

Notes:

- vnstock 5.x is **not on PyPI**. It is served from `https://vnstocks.com/api/packages`.
- A free API key, if the founder registers one, raises the tier to "Community". It is read from the env var `VNSTOCK_API_KEY` and must never be committed.

## Steps

### 1. Dependency (supply-chain safe)

In `pyproject.toml`, take **only** vnstock from its own index:

```toml
[[tool.uv.index]]
name = "vnstocks"
url = "https://vnstocks.com/api/packages"
explicit = true

[tool.uv.sources]
vnstock = { index = "vnstocks" }
```

Pin `vnstock==5.1.0` and lock it. Add a README section on licence and usage: Community edition, development and closed beta only (SC-006, RSK-014).

### 2. Port (`providers/base.py`)

**Capabilities:** `Capability(StrEnum)` with SYMBOLS, QUOTES, ORDER_BOOK, DAILY_BARS, INDEX_BARS, GROUP_MEMBERS, INDUSTRIES, FUTURES_LIST, FUTURES_QUOTES, FINANCIALS, SESSION_STATS.

**Models** (Pydantic v2, `frozen=True`, no `float` fields):

| Model | Fields |
|---|---|
| `Provenance` | `provider: str`, `fetched_at: datetime (UTC)`, `source_ts: datetime \| None` |
| `SymbolInfo` | `code`, `name`, `exchange: Literal[HOSE, HNX, UPCOM] \| None` |
| `Quote` | `symbol`, `exchange`; `reference`, `ceiling`, `floor`, `open`, `high`, `low`, `price: Decimal \| None`; `bids` / `asks: tuple[BookLevel, ...]` (≤ 3 each, `BookLevel(price: Decimal, volume: int)`); `foreign_buy_volume`, `foreign_sell_volume: int \| None`; `matched_volume`, `matched_value: int \| None` (None on the Guest tier); `provenance` |
| `DailyBar` | `symbol`, `trade_date: date`, `open`, `high`, `low`, `close: Decimal`, `volume: int`, `value: int \| None`, `provenance` |
| `IndexBar` | same as `DailyBar`, prices in points |
| `GroupMembers` | `group`, `symbols: tuple[str, ...]`, `provenance` |

**Errors:** `ProviderError(provider, detail)`, `CapabilityUnavailable(provider, capability, tier)`, `RateLimited`.

**`MarketDataProvider` Protocol** (async):

- `name`
- `async capabilities() -> frozenset[Capability]` (it probes on first call)
- `list_symbols()`, `get_quotes(symbols)` (any length; the adapter batches), `get_daily_bars(symbol, start, end)`, `get_index_bars(code, start, end)`, `get_group_members(group)`, `list_futures()`, `get_order_book(symbol)`, `list_industries()`
- An unsupported call raises `CapabilityUnavailable`.

### 3. vnstock adapter (`providers/vnstock_adapter.py`)

- **Async wrapper:** vnstock is synchronous. Wrap every call in `asyncio.to_thread`, and pass every call through the rate limiter and the single-flight cache.
- **Capability probing:** at first use, call one cheap function per capability. A vnstock `EntitlementError` (match the class name or message, since the import path may vary) marks the capability unavailable. Cache the matrix for 6 h, and log it once as JSON (`{"provider":"vnstock","tier":"guest|community","capabilities":[...]}`).
- **API key:** if `VNSTOCK_API_KEY` is set, log in with it via vnstock's documented API (find it in the installed package; do not shell out). Never log the key.
- **Normalization (SC-012):**
  - Prices: `Decimal(str(x)).quantize(Decimal("0.01"))`.
  - **Equity `ohlcv` prices × 1000.**
  - Volumes: `int`.
  - NaN or None: `None`.
  - Bar dates: the date of `time` in Asia/Ho_Chi_Minh.
- **Unit sanity check:** when the last bar and a quote are both available, `abs(close*1 − reference) / reference < 0.15` must hold for the scaled bar. Otherwise raise `ProviderError("unit mismatch")`.
- **Batching:** `get_quotes` sends chunks of **50 symbols** per vnstock call.
- **History cap:** for `get_daily_bars`, if the tier is Guest, clamp `start` to `today − 365 days` and log the clamp. Never fabricate missing days.

### 4. Rate limiter and single-flight (`providers/limits.py`, ALG-03)

- **Async token bucket:** rate from `PROVIDER_RATE_PER_SEC` (default 1), burst 1. Inject a clock for tests.
- **`SingleFlight`:** concurrent calls with the same key share one in-flight call; the result is cached with a TTL (quotes 10 s, bars 30 min, symbols 6 h, groups 6 h).

### 5. Fixtures and tests

- **`scripts/record_fixtures.py`:** calls the real vnstock **once** and writes JSON fixtures to `tests/providers/fixtures/`:
  - `equity_list`
  - `price_board` for FPT, VNM, HPG
  - `ohlcv` for FPT, 30 days
  - `index_ohlcv` for VNINDEX, 30 days
  - `by_group` VN30
  - `futures_list`
  - one captured `EntitlementError` message

  Commit the fixtures.
- **Unit tests** (offline; monkeypatch the vnstock calls to return DataFrames built from the fixtures):
  - Normalization: Decimal everywhere, × 1000 on equity bars, not on index bars, NaN → None, dates in VN time.
  - The unit sanity check fails on a deliberately unscaled bar.
  - Entitlement error → `CapabilityUnavailable`, and the capability matrix reflects it.
  - Batching: 120 symbols → 3 calls.
  - Rate limiter: 3 calls at 1/s take ≥ 2 s on the fake clock.
  - Single-flight: 10 concurrent identical calls → 1 loader call.
  - History clamp on the Guest tier.
  - Provenance is present on every model.
- **Live test:** `tests/providers/test_live_vnstock.py` with `@pytest.mark.live`, excluded by default (`addopts = -m "not live"`). It fetches the quotes of FPT and VNM and 30 bars of FPT and checks the invariants.
- **Coverage:** `analytics.providers` ≥ 80%.
